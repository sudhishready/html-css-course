# html-css-course
learning html &amp; css by watching a video
The video I learned from - https://youtu.be/G3e-cpL7ofc

In ex-1: HTML Basics
 I learned the very basics on how to put text, buttons and links on a page using <p>, <button>, <a> and headings. Also learned what a class is and how href works.

  In ex-2: CSS Basics
 Started making things look good.Changed colrs, font sizes, added border-radius for rounded buttons, and used classes to target specific elements instead of all of them.

  In ex-3: Hovers, Transitions, Shadows
After styling the buttons I added hover and active states, transitions so the changes are animated and box-shadows.

In ex-4: Chrome DevTools & Box Model
Every element is a box margin is the space outside the box and padding is the space inside the  box. Stopped using height on buttons and switched it to padding lot more flexible.

In ex-5: Text Styles
Made paragraphs look proper used font, size, color, alignment, line spacing. Learned <span> to style one word inside a sentence differently.

In ex-6: HTML Structures
Learned the format in a Html file- <!DOCTYPE html>, <html>, <head>, <body>. Moved Css into a seperate file and linked it. Also pulled in a custom font from Google fonts.

In ex-7: Images and Text boxes
Added images with img tag and made them circular using border-radius 50%. Built text inputs and styled a search bar.

In ex-8: Css Display
Learned that Block elemnts take a full row while inline-block lets things sit next to each other while keeping padding and width working.
